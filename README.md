# 📝 Modern To-Do List

A sleek, responsive, and feature-rich To-Do list application built with vanilla **HTML5**, **CSS3**, and **JavaScript**. Designed with a modern UI and persistent local storage so your tasks are always saved.

## ✨ Features

* **Task Management:** Add, complete, and delete tasks seamlessly.
* **Filter Views:** Easily switch between **All**, **Active**, and **Completed** tasks.
* **Persistent Storage:** Uses browser `localStorage` to ensure tasks aren't lost on refresh.
* **Responsive Design:** Clean, centered card layout that looks great on both desktop and mobile devices.
* **Security:** Built-in HTML escaping to prevent XSS vulnerabilities.
